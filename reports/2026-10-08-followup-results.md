# DINOv2 및 V-JEPA 2 후속 실험 결과

작성일: 2026-10-08. R01 단일 장면의 탐색 결과이며 공식 논문 재현 또는 현장 배포 검증은 아니다.

## 결론

1. 동일 검출·추적 및 동일 평가 프레임에서 DINOv2 외관 특징이 CLIP보다 유리했다. 개선은 전체 화면에서 특히 컸다.
2. 객체 crop과 좌표 움직임의 단순 결합은 전체 화면 방식을 넘지 못했다. 객체 중심 구조의 우수성은 확인되지 않았다.
3. CPU 예비 실험에서 V-JEPA 2의 영상 특징은 전체 AUROC를 개선하지 못했고 DINOv2와의 max 결합도 이득을 보이지 않았다.
4. 저장된 DINOv2 특징의 시간 변화는 일부 영상과 AP에서 유용했지만, 전체 AUROC 개선은 확인되지 않았다.
5. 정상 데이터로 정한 임계값의 결과가 평가 조건에 따라 크게 달랐다. 높은 AUROC와 실용적인 경고 시스템을 구분해야 한다.

## 1. DINOv2 / CLIP 외관 비교

GroundingDINO의 검색어 `small object`, 검출 사각형, IoU 추적, crop 여백, 움직임 기록을 재사용했다. 전체 화면 및 객체 외관 인코더를 frozen CLIP ViT-B/32에서 frozen DINOv2-Small로 변경했다. 정상 영상 분할은 fit 01–27, scale 28–30, threshold 31–34다.

DINOv2-Small의 마지막 CLS 384차원 특징을 L2 정규화했다. resize/center-crop 기하는 기존 CLIP과 동일한 shortest side 224 / center crop 224이고 색상 정규화는 모델별 설정이다. PCA와 정상 사례 거리 방식 각각에서 동일 프레임을 비교했다.

| 방식 | CLIP PCA AUROC | DINOv2 PCA AUROC | CLIP 정상 사례 AUROC | DINOv2 정상 사례 AUROC |
|---|---:|---:|---:|---:|
| A: 전체 화면 | 0.6853 | **0.8270** | 0.6002 | **0.8555** |
| B: 객체 외관 | 0.5629 | **0.6261** | 0.6309 | **0.6463** |
| C: 좌표 기반 움직임 | 0.4623 | 0.4623 | 0.5991 | 0.5991 |
| D: 객체 외관 + 움직임 | 0.4935 | **0.5418** | 0.6317 | **0.6815** |

주 비교는 전체 3,685프레임 중 네 방식 모두 점수가 있는 3,042프레임이며 관측 비율은 82.55%다. C가 동일한 것은 외관 모델만 바꾼 실험의 정상적인 결과다.

A는 전체 프레임을 검사할 수 있다. 전체 3,685프레임에서 DINOv2 정상 사례 방식의 AUROC는 0.8352, AP는 0.6006이다. 공통 프레임 AUROC 0.8555, AP 0.6814와 평가 집합이 다르다.

정상 기반 임계값에서 A의 이상 탐지율은 99.92%, 정상 오경보율은 45.70%였다. PCA A는 이상 탐지율 100%, 정상 오경보율 53.39%였다. 따라서 높은 순위 성능에도 불구하고 현재 전체 화면 경고 기준은 실용적이지 않다.

영상별로 모든 이상 구간을 잘 찾는 것은 아니다. 정상 사례 A의 영상 01 AUROC는 0.3798이다. 영상 08의 0.9484는 공통 집합에서 정상 프레임이 4개뿐이므로 일반화하지 않는다. 전체 지표에는 영상 사이 점수 차이의 영향도 포함된다.

CPU에서 DINOv2 특징 추출은 총 약 5,828초, 97분이었다. 이 시간은 기록된 영상별 추출 시간의 합이며 초기 다운로드·복구·평가를 제외한다.

## 2. V-JEPA 2 CPU 실험 설정

| 항목 | 설정 |
|---|---|
| 모델 | `facebook/vjepa2-vitl-fpc64-256` |
| 모델 revision | `b3c1679b7c34d3255ef3547f27c7b226aefab26f` |
| 라이브러리 | Transformers 4.57.1 |
| 입력 | 전체 화면의 고정 중앙 crop, 실제 연속 과거 16프레임 |
| 공간 해상도 | 256×256 |
| 평가 간격 | 영상별 32프레임 |
| 출력 | 마지막 encoder token 평균, L2 정규화, 1024차원 |
| 가중치 | 사전학습 모델 고정, predictor 미사용 |
| 실행 | CPU, float32 |
| 정상 분할 | 01–27 fit / 28–30 scale / 31–34 threshold |
| 임계값 | 분리된 정상 데이터의 99분위수 |

공식 체크포인트의 설정은 64프레임·256해상도다. 이번 CPU 예비 실험은 입력 길이를 16으로 줄였다. 수동 전처리는 shortest side 256 / center crop 256 / bicubic / ImageNet 정규화로, 공식 processor의 shortest side 292 설정과 차이가 있다.

입력은 객체 crop이 아니라 전체 화면이다. V-JEPA 2는 객체 검출·추적을 대신하지 않는다. 이번 결과를 객체 중심 V-JEPA 실험이라고 부르지 않는다.

전체 49개 영상에서 349개의 clip을 추출했다. 순서를 뒤집거나 마지막 프레임을 반복한 정상 구간의 특징도 점검했으나 이 probe를 학습·스코어 선택에 사용하지 않았다. 민감도 확인만으로 시간적 이상 탐지 효과가 증명되는 것은 아니다.

## 3. V-JEPA와 비교한 기준 모델

| 코드 | 설명 |
|---|---|
| G | 마지막 프레임의 기존 DINOv2 전체 화면 특징 |
| T | 같은 16프레임 DINO 특징의 평균 + 마지막-처음 변화 + 평균 절대 프레임 차이 |
| C | 마지막 시점의 기존 10프레임 객체 위치·크기·이동량 |
| V | V-JEPA 2 영상 특징 |
| GV | 정상 데이터로 스케일을 맞춘 G와 V 점수의 최댓값 |

T는 각 블록을 정규화한 뒤 결합해 최종 L2 정규화했다. T는 저장된 특징으로 계산했으며 추가 DINO 추론은 없다. C는 시간 창 길이가 다르므로 참고 비교다. V의 특징은 외관과 시간 정보를 함께 포함할 수 있다.

PCA와 정상 사례 거리 두 점수 방식을 사용했다. G/T/C/V 모두 이번 sparse 평가의 정상 시점에서 기준을 다시 만들고 정상 보정을 수행했다. 기존 전체 프레임 G의 점수를 단순히 일부만 뽑은 실험이 아니다.

## 4. 평가 범위

| 항목 | 수 |
|---|---:|
| 원래 전체 테스트 프레임 | 3,685 |
| 샘플링한 평가 시점 | 113 |
| 모든 방법이 점수가 있는 공통 시점 | 96 |
| 공통 시점 중 이상 | 38 |
| 공통 시점 중 정상 | 58 |
| 샘플링한 시점 중 전체 이상 | 40 |
| 샘플링한 시점 중 전체 정상 | 73 |

공통 관측 비율은 96/113=84.96%다. 샘플링 시점은 원래 프레임의 약 3.07%이며 미관측 시점을 보간하거나 정상 판정으로 채우지 않았다. 각 clip의 마지막 시점 라벨을 사용하며 이전 프레임에만 이상이 있었다는 이유로 라벨을 변경하지 않았다.

이 표의 AUROC를 이전 공통 3,042프레임에서의 0.8555와 직접 비교하지 않는다. 데이터 샘플링 및 정상 기준 생성에 사용한 관측 수도 달라졌다. 이번에는 같은 평가 시점에서 다시 계산한 G와 비교한다.

## 5. 전체 순위 성능

공통 96개 시점에서 계산한 결과다.

| 특징 | PCA AUROC | 정상 사례 AUROC | PCA AP | 정상 사례 AP |
|---|---:|---:|---:|---:|
| G: DINO 한 프레임 | **0.7831** | **0.7990** | **0.5936** | 0.6293 |
| T: DINO 시간 특징 | 0.6906 | 0.7346 | 0.5716 | **0.6754** |
| C: 객체 좌표 움직임 | 0.5649 | 0.6352 | 0.4544 | 0.5141 |
| V: V-JEPA 2 | 0.4823 | 0.4487 | 0.3640 | 0.4140 |
| GV: DINO + V-JEPA | 0.7831 | 0.7990 | 0.5936 | 0.6293 |

V-JEPA 2는 이 설정에서 전체 구분 성능을 개선하지 못했다. 정상 사례 T의 AP는 G보다 높지만 AUROC는 낮아 전체 성능이 일관되게 개선됐다고 주장하지 않는다.

GV는 G와 모든 표 지표가 동일하다. 정상 사례 방식의 원본 frame_scores.csv 확인 결과, 113개 시점 중 V 점수가 G보다 커진 시점은 3개였다. 대부분의 시점에서 G가 max 결합을 지배했으며, 바뀐 점수도 전체 순위 및 경고 지표의 이득으로 이어지지 않았다. 따라서 의미 있는 보완이 확인되지 않았다.

## 6. 경고 기준 결과

정상 사례 비교 방식에서의 결과다. 이상 탐지율의 분모는 샘플링한 이상 시점 40개이며 정상 오경보율은 각 방법의 관측 가능한 정상 시점에서 계산했다.

| 특징 | 탐지한 이상 시점 | 이상 탐지율 | 정상 오경보율 |
|---|---:|---:|---:|
| G | 0/40 | 0.0% | 0.0% |
| T | 13/40 | 32.5% | 9.59% |
| C | 1/40 | 2.5% | 6.90% |
| V | 4/40 | 10.0% | 9.59% |
| GV | 0/40 | 0.0% | 0.0% |

C의 정상 분모는 58개, 다른 방법은 73개다. 같은 오경보율에서 성능을 비교한 표는 아니다. T와 V는 같은 정상 오경보 수 7개로, T가 더 많은 이상 시점을 잡았지만 표본이 작고 독립 반복 검증이 없어 우수성을 일반화하지 않는다.

이번 G에서는 정상 임계값 1.6021보다 높은 테스트 점수가 없었다. 점수 범위는 약 0.7545–1.5975였다. 이는 높은 AUROC에도 실제 경고가 발생하지 않는 사례다. 이전 전체 프레임 DINO 결과에서 오경보가 많았던 것과 반대여서 정상 기준·표본·보정 조건에 대한 민감도 분석이 중요하다. 어느 임계값도 테스트 정답을 보고 맞추지 않았다.

## 7. 영상별 해석과 한계

정상 사례 기준의 영상별 AUROC다.

| 영상 | 공통 정상/이상 수 | G | T | C | V |
|---|---|---:|---:|---:|---:|
| 01 | 1 / 5 | 0.400 | 0.800 | 1.000 | 0.800 |
| 02 | 3 / 4 | 0.500 | 0.500 | 1.000 | 0.750 |
| 03 | 5 / 6 | 0.633 | 0.867 | 0.933 | 1.000 |
| 04 | 2 / 3 | 0.667 | 0.667 | 0.333 | 0.500 |
| 05 | 5 / 3 | 0.467 | 1.000 | 1.000 | 0.867 |
| 07 | 1 / 5 | 0.200 | 0.400 | 0.200 | 0.000 |

Vは 일부 영상에서 이상 구간 구분에 도움이 되지만 전체 점수는 낮았다. 전체 지표는 영상 간 점수 차이에도 영향을 받는다. 영상별 정상 시점이 1–5개뿐인 경우가 있어 1.0 또는 0.0을 안정적인 증거로 해석하지 않는다. 06·08 및 정상 전용 09–15는 공통 집합에 한 종류의 라벨만 있어 영상별 AUROC를 계산할 수 없다.

가능한 원인은 짧은 입력 길이, 작은 제품의 변화가 token 평균에서 약해지는 현상, 사전학습 도메인 차이, 영상 간 점수 차이 및 정상 보정 문제 등이다. 현재 결과로 이 중 특정 원인을 확정하지 않았다. 사전학습 predictor의 예측 오차, object tube, patch 기반 점수, 다른 모델 버전은 실험하지 않았다.

## 8. 처리 비용

V-JEPA 특징 추출 기록의 합은 약 12,625초, **3시간 30분**이다. 첫 추론은 약 35.9초였고, 전체 349개 구간을 CPU에서 처리했다. 다운로드·캐시 확인·데이터 복구·평가 시간을 포함한 전체 노트북 시간이 아니다. 실시간 성능을 검증한 결과가 아니다.

이미지·영상 인코더 추출은 캐시를 저장했다. 추가 정상 점수 분석 및 기존 T/G 결합은 캐시로 수행할 수 있으나, 입력 길이·해상도·영상 범위·인코더를 바꾸면 새 영상 특징 추출이 필요하다.

## 9. 지금 공유 가능한 주장

> R01에서 이미지 표현과 정상 비교 방식의 영향을 실험했다. DINOv2는 CLIP보다 외관 구분 성능을 개선했으며, 객체 중심 구조의 일관된 이득은 확인되지 않았다. CPU 예비 실험에서 V-JEPA 2 도입은 전체 성능을 높이지 못했다. DINOv2 특징의 시간 변화는 일부 영상과 AP에서 도움이 됐지만 AUROC와 경고 성능은 별도로 해석해야 한다. 정상 데이터 기반 점수 보정과 영상 간 편차를 분석하는 것이 다음 우선순위다.

단순한 모델 교체 또는 결합이 새로운 알고리즘이라는 주장은 하지 않는다. 아직 다른 장면, 반복 설정, 통계적 불확실성, 이상 유형 라벨링, 낮은 오경보율 및 일반화된 온라인 조건을 검증하지 않았다.

## 10. 다음 작업

회의 및 GitHub 결과 공유를 위해 추가 대형 모델 추론이 필수인 상태는 아니다. 이번 결과를 먼저 정리한다.

연구를 더 진행한다면 다음 순서가 적절하다.

1. 저장된 DINOv2 특징으로 T를 전체 시점에서 평가해 sparse 표본에 의존한 결과인지 확인한다.
2. 정상 데이터에서만 정한 동일 오경보 목표로 G/T의 보정 민감도를 비교한다. 테스트 라벨로 임계값 또는 결합 가중치를 고르지 않는다.
3. 정상 영상으로 설계한 G+T 결합을 비교하되, 개선 여부를 미리 가정하지 않는다.
4. 실제 이상 내용을 확인하고 개선안을 고정한 뒤 다른 공정에서 평가한다.

이번 파일과 JSON은 결과 공유 자료다. 현재 실행 스크립트는 사용자의 기존 R01 결과 경로를 참조하므로 외부 사용자 재현을 위해 경로 설정 및 전체 실행 검증이 추가로 필요하다.
